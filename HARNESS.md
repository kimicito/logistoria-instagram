## Правила работы

### 1. План → Согласование → Выполнение
**Любое изменение в работе Instagram:**
1. Показать план действий
2. Получить согласие пользователя
3. Только потом выполнять

### 2. "Человеческое" поведение (обязательно!)
- **Время публикаций:** Только рабочие часы целевых рынков
- **Интервалы:** ±30 минут от планового времени
- **Частота:** Максимум 1 пост + 2-3 Stories в день
- **Ответы на заявки:** 30 мин — 4 часа (не мгновенно)
- **Язык:** Дружелюбный, экспертный, без агрессивных продаж

### 3. Безопасность токена
- Хранить в `.env` (не в git!)
- `.env` в `.gitignore`
- При компрометации — отозвать в Facebook Developers
- Никогда не логировать токен

### 4. Обработка заявок
**Что считать заявкой:**
- Комментарий со словами: "сколько стоит", "how much", "cuánto cuesta"
- Запрос демо/котировки
- Вопрос о доставке/Print&Play

**Что НЕ заявка:**
- Лайки и эмодзи без текста
- "Круто!" без вопроса о покупке

### 5. Git дисциплина
```bash
git add -A
git commit -m "[instagram] Описание изменений"
git push origin master
```

## Типичные задачи

### Добавить новый продукт (игру)
1. Добавить данные в `GAMES` в `instagram_poster.py`
2. Добавить фото в `images/`
3. Добавить шаблоны постов в `POST_TEMPLATES`
4. Обновить контент-план

### Изменить расписание
1. Отредактировать cron (crontab -e)
2. Обновить `MARKETS` в `instagram_poster.py`
3. Уведомить пользователя

### Обработать жалобу/бан
1. Проверить логи (`logs/instagram.log`)
2. Уменьшить частоту публикаций
3. Проверить токен (возможно, истёк)
4. Обновить контент (менее "продающий")

## Критические проверки

| Проверка | Когда |

| Токен не истёк | Ежедневно |
| Лимиты API не превышены | После каждой публикации |
| Заявки обработаны | Каждые 2 часа |
| Email уведомления работают | Еженедельно |
| Контент не повторяется | Еженедельно |

## Проблемы и решения

### Токен истёк (Error 190)
**Решение:** Перегенерировать в Graph API Explorer → обновить `.env`

### Rate limit exceeded (Error 4)
**Решение:** Подождать 1 час → уменьшить частоту в cron

### Фото не загружается (Error 2207027)
**Решение:** Проверить, что URL публично доступен → использовать HTTPS

### Комментарии не приходят
**Решение:** Проверить webhook (если настроен) → использовать polling (`check_leads.py`)
